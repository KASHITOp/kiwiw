# Kiwiw — REFERENCES.md

Six template style directions. Every Kiwiw template, every Juice It poster and
every Vibe slider position is built from one of these. They are original
directions written for Kiwiw; nothing here copies a product's look.

## What we borrowed (structure, not looks)

Studied the getdesign.md breakdowns of **Framer, Clay, Nike, The Verge and
Spotify** for rigor only:

| Lesson | From | How Kiwiw uses it |
| --- | --- | --- |
| Every token comes with one hard rule, not just a value. | Nike | Each direction below has a **Never** line. |
| Type roles are named by their job ("X shouts, Y labels"). | The Verge | Each direction names a *shout*, a *talk* and a *label* face. |
| One signature move per system. | Framer, Clay | Each direction has exactly one **Signature** element. |
| Depth is decided, not defaulted (flat vs colour-as-elevation). | Nike, The Verge | Each direction states its depth rule. |
| Responsive/format rules live in a table. | All five | Format map at the bottom. |

All fonts below are Google Fonts loaded through Fontsource. All shapes and
stickers are Kiwiw's own SVG. No stock photos are used in templates (see
LICENSES.md); if a direction wants a "photo", it gets a drawn duotone block.

## 1 · BLOCK CAPITALS (brutalist / Swiss bold type)

**Mood:** shouting, but with a ruler. A gym flyer that went to design school.

| | |
| --- | --- |
| Shout | Anton, uppercase, tracking −0.01em, line-height 0.86 |
| Talk | Archivo Black |
| Label | Space Mono, uppercase, +0.12em |
| Palette | Paper `#F1EFE8` · Ink `#0B0B0B` · Signal red `#FF3B1F` (one accent, ≤ 15% of the area) |
| Depth | Flat. No shadows, no radius, ever. |

**Layout rules**
- Flush-left on a hard 12-column grid; margins 6% of the short side.
- Type is the image: the headline fills ≥ 55% of the width and may bleed off an edge.
- Hairline rules (2px ink) separate zones; index numbers (`01`, `02`) in mono.
- At most one sticker: a single red starburst or arrow.

**Signature:** a giant numeral or word cropped by the canvas edge.
**Never:** centre anything, round a corner, or use more than one accent.
**Joke:** "Kerning? We don't negotiate."

**Templates:** Basement Rave Poster (poster) · Loud Job Post (LinkedIn banner) · I Tried 47 Fonts (YouTube thumb) · No Pain No Plain (IG post)

## 2 · THE SUNDAY ISSUE (editorial magazine)

**Mood:** expensive paper, slow coffee, a headline that sighs.

| | |
| --- | --- |
| Shout | Instrument Serif (italic for the emphasised word), big and light |
| Talk | Inter 400 |
| Label | Space Mono folios: `ISSUE 07 · NOV`, page numbers |
| Palette | Cream `#F4EEE3` · Ink `#1B1A17` · Tomato `#E8553B` · Sage `#8E9C7C` |
| Depth | Flat; separation by rules and whitespace. |

**Layout rules**
- Masthead or folio line at the top, always.
- Generous margins (8% of width); text columns never wider than 60% of the page.
- One italic word per headline does the emotional lifting.
- Pull quotes in serif at 2× body, with a tomato rule.
- Stickers allowed: squiggle underline, one hand-drawn arrow. Nothing loud.

**Signature:** the masthead + issue folio.
**Never:** all-caps body, more than two colours on one page besides ink.
**Joke:** "Reading time: 4 min. Pretending you read it: 12 sec."

**Templates:** The Overachiever Resume (poster) · Long Read, Short Attention (IG post) · Sunday Keynote (slide) · Recipe Card Gone Fancy (story)

## 3 · CUT & PASTE CLUB (sticker / zine collage)

**Mood:** photocopier at 2 a.m., glue stick, zero regrets.

| | |
| --- | --- |
| Shout | Permanent Marker, or Rubik Mono One for ransom-note blocks |
| Talk | Caveat |
| Label | Space Mono on tape strips |
| Palette | Kraft `#E9DCC4` · Ink `#111111` · Hot pink `#FF4FA3` · Kiwi `#8BD630` · Tangerine `#FF7A1A` |
| Depth | Paper on paper: rotated layers with hard offset shadows (`6px 6px 0 #111`). |

**Layout rules**
- Nothing sits at 0°: rotate blocks ±2–8°.
- Tape strips pin things down; torn edges frame things up.
- Ransom-note headlines: each word in its own coloured block, alternating fonts.
- Halftone dots and grain fill the dead space.
- Stickers are encouraged: 4–8 per piece.

**Signature:** taped, rotated paper blocks with a hard shadow.
**Never:** perfectly aligned edges, more than three typefaces.
**Joke:** "Copyright © whoever owns the glue stick."

**Templates:** Garage Band Gig (poster) · Thrift Haul Story (story) · Lost Cat (It's a Sale) (IG post) · Craft Fair, Chaotic Good (LinkedIn banner)

## 4 · BOMBAY TALKIES PRESS (retro Indian print · the Desi pack)

**Mood:** single-screen cinema poster, matchbox label, hand-painted signboard.

| | |
| --- | --- |
| Shout | Baloo 2 ExtraBold (Latin + Devanagari) |
| Talk | Mukta |
| Label | Rubik Mono One for prices and stamps |
| Accent script | Tiro Devanagari Hindi for the Hindi line |
| Palette | Marigold `#F6A21E` · Vermilion `#D7261E` · Peacock `#0F6E6E` · Cream `#F7E7C6` · Kattha `#2A160E` |
| Depth | Printed: double borders and stamped circles, no soft shadows. |

**Layout rules**
- Symmetric and centred (the one direction that may centre everything).
- A double-rule ornamental border frames the page.
- Sunburst rays or a marigold behind the title.
- Bilingual: one Hindi/Hinglish line on every piece.
- Price or date lives in a stamped circle ("ONLY ₹10").

**Signature:** sunburst behind a bilingual title, inside a double border.
**Never:** minimalism. Never more than five colours.
**Joke:** "Now showing: 3 shows daily, 4 if the projectionist had chai."

**Templates:** Fest Poster That Actually Gets Crowd (poster) · Chai Break Menu (story) · Diwali Sale But Make It Fashion (IG post) · Shaadi Save-the-Date, Mummy Approved (story)

## 5 · QUIET MONEY (clean premium)

**Mood:** a series-A deck in a linen shirt. Says less, charges more.

| | |
| --- | --- |
| Shout | Fraunces 300–400, optical size high, tight |
| Talk | Inter 400 |
| Label | Space Mono small caps-ish labels, +0.14em |
| Palette | Bone `#EDEAE3` · Graphite `#191A17` · Moss `#4F5D3A` · Brass `#B08A4E` |
| Depth | Flat, with one hairline frame. |

**Layout rules**
- Margins ≥ 10% of width. Whitespace is the hero.
- Max two colours per piece plus ink.
- One focal object (a number, a product block, a single kiwi) per canvas.
- Labels in mono, everything else in two sizes only.
- Stickers: none, or one tiny kiwi.

**Signature:** a single, enormous, light-weight number or word floating in space.
**Never:** exclamation marks, starbursts, more than two type sizes per block.
**Joke:** "So minimal the font is on a juice cleanse."

**Templates:** Investor Bait (slide, Hinglish, Desi pack) · Quietly Hiring (LinkedIn banner) · Linen Shirt Launch (IG post) · Calm Webinar Energy (YouTube thumb)

## 6 · BRAINROT BROADCAST (chaotic Gen-Z meme)

**Mood:** group chat at 3 a.m., everybody typing.

| | |
| --- | --- |
| Shout | Rubik Mono One or Anton with a black outline and hard shadow |
| Talk | Gochi Hand |
| Label | Space Mono "UI chrome": timestamps, fake chips, `▶ 0:07` |
| Palette | Acid `#D8F27A` · Hot pink `#FF3FA4` · Ink `#0B0B0B` · White `#FFFFFF` · Alert red `#FF2D2D` |
| Depth | Sticker-flat with chunky outlines; hard drop shadows only. |

**Layout rules**
- Meme captions: outlined type at top and bottom.
- Arrows pointing at things that don't matter. Starbursts that scream "NEW".
- Fake UI: progress bars, `W`/`L` chips, a fake notification.
- Deliberate misalignment (a 2–4° tilt on one block, never all of them).
- Stickers: 5–10, overlapping.

**Signature:** the outlined meme caption + one fake UI element.
**Never:** a calm moment. Never two blocks at the same tilt.
**Joke:** "This poster has no thoughts, only vibes."

**Templates:** Ratio'd Announcement (IG post) · POV: You Opened The Story (story) · Clickbait But Honest (YouTube thumb) · Main Character Banner (LinkedIn banner)
