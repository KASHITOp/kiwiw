## Assets & content

- All templates, colors and sample copy shipped in Kiwiw are original to this
  project.
- The demo photo library uses [picsum.photos](https://picsum.photos) placeholders
  by default; real photo search is powered by [Pexels](https://www.pexels.com)
  when an API key is supplied, under the Pexels license.

Run `npm run build` and inspect `node_modules` for the full, authoritative
license text of every transitive dependency.

## Stickers

Every illustrated sticker (268 and counting) is original SVG drawn in
`src/stickers/`. No brand logos, product names, celebrities, film titles,
lyrics or copyrighted characters are used, and every phrase on a sticker or
template is written for Kiwiw. The only photo stickers are the Pexels cats
listed above.

## Style references

`STYLE_DNA.md` was derived from a personal reference board. Only techniques
(halftone, stamp frames, warped type, grids, palettes) were used. No layout,
artwork, brand, person or character from the board is reproduced.
